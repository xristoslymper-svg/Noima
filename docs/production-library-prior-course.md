# Επιλεκτική μεταφορά Βιβλιοθήκης και προηγούμενης πορείας

## Συμφωνημένο όριο

Βάση είναι το production `27e61cefd3a7bb568a73a02a4e08ebf70a9a762a`. Δεν γίνεται merge των #108/#109. Η πηγή για τις επιλεγμένες βελτιώσεις Βιβλιοθήκης είναι το `a095f231c97bd653f110b152ff4c7144f9f84645`, προσαρμοσμένη στα υπάρχοντα Ελληνικά χωρίς συνολικό i18n refactor.

### Παραμένουν ως έχουν

Ασθενείς/δημιουργία φακέλου, ημερολόγιο, header και ονομασίες **Σύνοψη | Επισκέψεις | Θεραπευτικό πλάνο | Στοιχεία & ιστορικό**, κλινική σύνοψη, αγωγή, ενεργή καταγραφή επίσκεψης, draft/finalize, κοινά styles, authorization και dependency lockfile. Το `tests/selective-production-contract.json` καταγράφει SHA256 για 25 production αρχεία. Το PatientWorkspace έχει μόνο τη σύνδεση της νέας ενότητας στις Επισκέψεις.

### Βιβλιοθήκη

- Επιλογή υπάρχοντος/νέου παραλήπτη από το συγκεκριμένο εργαλείο και κανάλι, χωρίς επαναληπτική επιλογή εργαλείου.
- Αρχικό ιστορικό και οι υπάρχουσες ενεργές αναθέσεις PHQ-9/GAD-7, με email, tablet και εκτύπωση. Οι υπόλοιπες κάρτες διατηρούν την υπάρχουσα διαθεσιμότητά τους.
- Πληρέστερα στοιχεία ταυτοποίησης/επικοινωνίας στην υποβολή νέου ασθενή, με τις υπάρχουσες SQL διαδρομές ταυτοποίησης και δημιουργίας φακέλου. Η αποστολή πρόσκλησης δεν δημιουργεί φάκελο ή επίσκεψη.
- Επιβεβαιωμένη υποβολή δημιουργεί/συνδέει φάκελο. Αμφισημίες παραμένουν προς έλεγχο στο υπάρχον workflow, όχι αυτόματη συγχώνευση.
- Οι προσπάθειες επανάληψης email χρησιμοποιούν την ίδια ανάθεση. Άνοιγμα έτοιμου email δεν σημαίνει αποστολή.
- **Η εκτύπωση διατηρεί τον κωδικό ανάθεσης του production.** Δεν μεταφέρεται η ασύμβατη εκτύπωση χωρίς κωδικό του μεγάλου preview: ο υπάρχων scanner απαιτεί κωδικό. Το scan API και οι κανόνες του παραμένουν αμετάβλητοι.

### Προηγούμενη κλινική πορεία

Μόνο στις **Επισκέψεις**: ένα κουμπί ανοίγει inline προαιρετική περίοδο και κείμενο, με υπαγόρευση, ρητή αποθήκευση και επεξεργασία. Η αναδρομική καταχώριση δεν αυξάνει τον αριθμό επισκέψεων, δεν δημιουργεί session/appointment και δεν αλλάζει αγωγή, κίνδυνο ή κλινική σύνοψη. Η ημερομηνία εισαγωγής αναγράφεται ως ημερομηνία καταχώρισης, όχι ως παλιά επίσκεψη.

Διατηρούνται τοπικό πρόχειρο, guard κατά την αλλαγή καρτέλας, version conflict, επανάληψη του ίδιου αιτήματος και επαλήθευση ταυτότητας/περιεχομένου στην απόκριση. Το αρχικό κείμενο του θεράποντος αποθηκεύεται χωρίς AI αναδιατύπωση. Η υπαγόρευση προσθέτει κείμενο προς έλεγχο πριν το Save.

## Βάση και ασφάλεια διάθεσης

Η migration `20261016183701_patient_prior_course.sql` αντιγράφεται απαράλλακτη για fresh isolated databases και έχει ήδη εμφανιστεί στο hosted ledger. Δεν εκτελείται migration στην κοινή βάση. Δεν εισάγονται οι τρεις νέες migrations του #109 ή το νέο medication_register.

Αυτό δεν αποτελεί καθολική αποκατάσταση παλαιών ανεφάρμοστων identity safeguards ή επιβεβαίωση πλήρους κλινικής ετοιμότητας. Δεν αλλάζει παλιές εγγραφές ή κάνει αυτόματη συγχώνευση φακέλων.

## Επαλήθευση

- Unit checks: production source hashes, ακριβές scope σύνδεσης, input/output identity validation, διατήρηση print code και retry συμβολαίων.
- Disposable PGlite: πραγματικές migrations/RPCs, δύο λογαριασμοί, version/retry checks, δημιουργία φακέλου μόνο στην υποβολή, μη δημιουργία συνεδριών/ραντεβού.
- Chromium desktop/mobile: πραγματικά React components και πραγματικά intake/prior-course API handlers πάνω σε απομονωμένο PGlite. Μόνο auth transport, αναγνώσεις υπάρχοντος φακέλου, email και transcription είναι συνθετικά.
- Οι έλεγχοι περιλαμβάνουν χαμένη απόκριση μετά από commit, ίδιο request ID στην επανάληψη, επαναφόρτωση, ακύρωση, αλλαγή tab με πρόχειρο, συνθετικό μικρόφωνο, νέα υποβολή και εκτύπωση με κωδικό.

Τα commit-specific CI αποτελέσματα και το preview καταγράφονται στο PR #110 μετά την ολοκλήρωση. Οι προηγούμενες αποτυχημένες δοκιμές προετοιμασίας δεν αποτελούν τελική πιστοποίηση.

## Όρια

Δεν έχουν γίνει εγγραφές σε hosted κλινική βάση, πραγματικές αποστολές email, δοκιμή φυσικού μικροφώνου ή αξιολόγηση ακρίβειας provider. Το browser fixture δεν αποτελεί πλήρες hosted Supabase/Auth E2E. Καμία δημοσίευση σε production ή merge στο main δεν έχει γίνει από αυτή την εργασία.
